Scientific Calculator Formula

sin(θ) — sine of an angle  •  cos(θ) — cosine  •  tan(θ) — tangent

log10(x) — base-10 logarithm  •  ln(x) — natural logarithm, base e

x^y — x to the power y  •  √(x) — square root  •  x! = 1 × 2 × … × x

Trigonometric functions follow the angle mode shown above the keypad: in degrees mode, sin(30°) = 0.5, and in radians mode the same button expects the angle in radians. Inverse functions (asin, acos, atan) return the angle in the current mode. Percentages work as you expect on a handheld calculator: 50% is 0.5, so 200 × 50% = 100.

Worked examples (degrees mode): sin(30°) = 0.5; cos(60°) = 0.5; log10(100) = 2; ln(e) = 1; 2^10 = 1024; √(144) = 12; 5! = 120; 3² + 4² = 25.

Frequently Asked Questions

Degrees vs radians — which should I use?

Use degrees for most school and everyday maths — angles in triangles, bearings and geometry are usually given in degrees. Use radians for calculus, physics and most programming, where angles are measured in radians. This calculator starts in degrees; tap the DEG/RAD button to switch, and the current mode is shown above the keypad.

What is the difference between log and ln?

log is the base-10 logarithm, so log(100) = 2 because 10² = 100. ln is the natural logarithm, base e (about 2.71828), so ln(e) = 1. Use log for decibels, pH and orders of magnitude, and ln for growth, decay and calculus.

How do I use ANS?

ANS recalls the last answer this calculator produced. After a calculation, tap ANS to insert that value into a new expression — for example, after working out 2^10 = 1024, tap ANS, then + 1, then = to get 1025. The keyboard shortcut is the A key.

Why does 1 ÷ 0 show an error?

Division by zero has no defined answer in mathematics, so the calculator shows Error instead of guessing. The same happens for log(0), ln of a negative number, the square root of a negative number, and factorials of negative or non-whole numbers — clear the error with C and try a valid input.

Which keyboard keys work?

Digits 0–9, the decimal point, + − * / (or × ÷), ^ for powers, % , ! for factorial, parentheses, Enter or = to calculate, Backspace to delete, and Escape to clear. Press A for ANS, D to switch between degrees and radians, and P for π.
