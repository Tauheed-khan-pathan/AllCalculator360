How to Convert to Roman Numerals

To convert a number to Roman numerals, break it into thousands, hundreds, tens and ones, then write each part with Roman symbols, largest first. The symbols are I = 1, V = 5, X = 10, L = 50, C = 100, D = 500 and M = 1000. Symbols are added together, except that a smaller symbol before a larger one is subtracted: IV is 4, IX is 9, XL is 40, XC is 90, CD is 400 and CM is 900.

Roman numerals still appear on clock faces, book chapters, film copyright years and the names of kings and popes. If you need the year itself for a calculation, the Date Calculator counts days between dates, and the Scientific Calculator handles ordinary arithmetic on the converted number.

Roman Numeral Rules

I = 1   V = 5   X = 10   L = 50   C = 100   D = 500   M = 1000

Subtractive pairs: IV = 4   IX = 9   XL = 40   XC = 90   CD = 400   CM = 900

Rules: symbols in descending order • no symbol repeats more than 3 times • V, L and D never repeat • subtraction only with IV, IX, XL, XC, CD and CM

Roman Numeral Example

Worked example: 2026 = 2000 + 20 + 6 = MM + XX + VI = MMXXVI. Reading it back: M + M + X + X + V + I = 1000 + 1000 + 10 + 10 + 5 + 1 = 2026.

Worked example: 1999 = 1000 + 900 + 90 + 9 = M + CM + XC + IX = MCMXCIX. Note that 900 is CM, not DCCCC, and 90 is XC, not LXXXX. The largest standard numeral is 3999 = 3000 + 900 + 90 + 9 = MMMCMXCIX — a year often seen in film credits is 1999, so the Date Calculator is handy for working out how long ago that was.

Worked example: 42 = 40 + 2 = XL + II = XLII, and 1 = I. Invalid input is rejected: IIII is not 4 (use IV), VV is never valid, and IC is not 99 (use XCIX).

Frequently Asked Questions

What is 2026 in Roman numerals?

2026 in Roman numerals is MMXXVI. Break it into 2000 + 20 + 6: 2000 is MM, 20 is XX and 6 is VI, so together they make MMXXVI. Type 2026 in the number box above and the converter shows MMXXVI instantly.

How do you convert Roman numerals to numbers?

Add up the value of each symbol, but subtract a symbol when a smaller one comes before a larger one: in IX, the I before the X means 10 − 1 = 9. For example, MMXXVI is 1000 + 1000 + 10 + 10 + 5 + 1 = 2026. Type the Roman numeral in the box above and the converter works it out for you.

What is the largest number in Roman numerals?

The largest number in the standard system is 3999, written as MMMCMXCIX. Roman numerals have no symbol for zero and no place value, so numbers above 3999 need extra notation such as a bar over the symbols, which this converter does not use. Enter any number from 1 to 3999 above.

Why is IIII not a valid Roman numeral?

IIII is not valid because a symbol may repeat at most three times in a row, and 4 is always written with subtraction as IV, not IIII. The same rule rejects VV, LL and DD, which are never valid, and IC, which is not a correct subtraction — 99 is XCIX, not IC. The converter above shows a friendly error for any numeral that breaks these rules.

What are the Roman numeral symbols?

There are seven symbols: I = 1, V = 5, X = 10, L = 50, C = 100, D = 500 and M = 1000. Larger numbers are made by adding symbols together, with six subtractive pairs for 4, 9, 40, 90, 400 and 900: IV, IX, XL, XC, CD and CM. For example, 1999 is MCMXCIX.

Can Roman numerals show zero or negative numbers?

No. The Roman system has no symbol for zero and no way to write negative numbers, so the converter only accepts numbers from 1 to 3999. If you enter 0, a negative number or a number above 3999, it shows a friendly error and asks for a number in range.
