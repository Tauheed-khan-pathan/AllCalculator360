How to Generate a Random Number

Pick a minimum and a maximum, choose how many numbers you want, and press Generate. Every whole number in the range has the same chance of coming up on each draw, and each draw is independent — so with duplicates allowed, the same number can appear twice in a row, just like rolling a die twice. If you need a set of different numbers, for a draw or a sample, uncheck "Allow duplicates" and the generator picks without replacement, like drawing names from a hat. To check the average of the numbers you generated, use the Average Calculator, and for how spread out they are, the Standard Deviation Calculator.

Random Number Formula

Whole number = floor(random × (max − min + 1)) + min

random = a value from 0 (inclusive) to 1 (exclusive), from Math.random()  •  min / max = the range you chose

Decimal number = min + random × (max − min), rounded to the decimal places you chose

For whole numbers, multiplying the random value by the size of the range (max − min + 1) and rounding down gives every value in the range an equal chance, including the maximum. For decimals, the same random value is stretched across the range and rounded to 1 or 2 decimal places.

Random Number Example

Worked example: to pick a random whole number from 1 to 10, the generator takes a random value — say 0.63 — and works out floor(0.63 × (10 − 1 + 1)) + 1 = floor(6.3) + 1 = 7. Run it again and you get a different random value, so a different number. A typical 5-number draw from 1 to 10 with duplicates allowed might look like 4, 9, 2, 7, 5 — but every draw is different, and no result is guaranteed.

Decimals example: with a range of 1 to 100 and 2 decimal places, the same method gives values like 42.37 — the random value is stretched across the range (1 + 0.414 × 99 = 41.99, and so on) and rounded to 2 decimal places.

No-duplicates example: to pick 3 different winners from 100 entries, set the range to 1–100, the count to 3, and uncheck "Allow duplicates" — you get 3 different numbers, for example 17, 58, 93 (your actual draw will differ).

How to Use the Random Number Generator

Set your range and count, then generate — the numbers update instantly whenever you change a setting.

  1. Enter the minimum and maximum of your range (for example 1 and 10, or 1 and 100).
  2. Choose how many numbers you want, whether duplicates are allowed, and whole numbers or decimals.
  3. Press "Generate again" for a fresh set, or use "Copy results" to paste the list anywhere.
  4. For a fair draw, turn duplicates off so nobody can win twice. To analyse a set of numbers, try the Average Calculator or the Percentage Calculator.

Frequently Asked Questions

How do I generate a random number between 1 and 100?

Set the minimum to 1 and the maximum to 100, choose how many numbers you want, and press Generate. The tool picks whole numbers with every value in the range equally likely — each draw is independent, so the same number can come up twice in a row when duplicates are allowed.

Can I generate random numbers without duplicates?

Yes — uncheck "Allow duplicates" and every number in your list will be different. The count you ask for must fit inside the range: with duplicates off, you cannot ask for more numbers than the range holds (for example, at most 10 different numbers between 1 and 10). If you ask for too many, the calculator caps the count at the size of the range and tells you.

Can I generate random decimal numbers?

Yes — choose 1 or 2 decimal places in the "Number type" box. With 2 decimal places, a draw between 1 and 100 might give 42.37. Whole numbers are the default, and the decimals option works with any minimum and maximum, including negative numbers.

Are the numbers really random?

They are pseudo-random, generated in your browser with JavaScript's Math.random(), which is random enough for games, draws, classroom picks and everyday decisions. They are not cryptographically secure random numbers, so do not use this tool for passwords, security codes or anything where unpredictability must be guaranteed.

How many numbers can I generate, and how big can the range be?

You can generate up to 100 numbers at a time, and the minimum and maximum can each be any whole number from -1,000,000 to 1,000,000, as long as the minimum is not above the maximum. If the minimum and maximum are equal, every result is that one number.

Can I use this for a lottery or a giveaway draw?

For a casual giveaway or classroom draw it works well: set the range to your number of entries, turn duplicates off, and generate one number per winner. But it gives no guarantee and no audit trail — it is not suitable for a regulated lottery, a paid draw or anything where the result could be disputed, because the numbers are Math.random-based and cannot be independently verified afterwards.
